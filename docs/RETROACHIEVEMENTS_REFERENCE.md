# RetroAchievements: Resident Evil (PlayStation) — set reference

Source: <https://retroachievements.org/game/29328> — "Resident Evil (PlayStation)",
the **original** release, not Director's Cut (that set is a separate game entry,
[11268](https://retroachievements.org/game/11268)).

**64 achievements, 615 points, official/core set.**

Collected here as reference material for our own achievement list
(`docs/ACHIEVEMENTS.md`). 60 of the 64 rows are below: the game page only
renders 20 rows per request, so it was paged by re-sorting (points asc/desc,
title asc/desc, won-by asc/desc). The 4 rows not captured are worth 20 points
between them.

Note: several descriptions carry a `[No Infinite RL]` tag — the set forbids the
unlockable infinite rocket launcher for those.

## How the set is built
A rough shape worth copying, since it is what makes the set feel complete
rather than grindy:

| band | count | what it rewards |
|---|---|---|
| 1-3 pts | 17 | collecting a specific item: every crest, both Shield Keys, Armor Key, Python, Battery, grenade launcher, lockpick |
| 5 pts | 11 | small story beats and unaided boss kills — fountain drained, Crest Door opened, serum delivered in time |
| 10 pts | 25 | boss kills under a restriction (weapon-limited, no healing, timed), each ending |
| 25 pts | 4 | full-game feats — sub-3-hour clear, best ending per character, knife-only Yawn |
| 50 pts | 3 | the three challenge runs — no weapons, no healing, no item box / no saving |

Almost everything is **doubled per character**: Jill and Chris have their own
version of the same beat, with different titles and often different points
(Chris usually costs more, since he has no lockpick and less inventory).

## What maps onto our engine cheaply
For porting these into `src/game/Achievements.cpp`, in rough order of effort:

1. **Item pickups** (17 of them) — one hook on the item-get path, keyed by item
   id. Crests, keys, Python, Battery, grenade launcher, lockpick.
2. **Boss kills** — the kill hook already exists (`apply_weapon_damage`); it just
   needs the enemy id and the room, which are both to hand.
3. **Endings** — `EndingScreen.cpp` already distinguishes which partners
   survived; that is exactly the 25/10-point ending fan.
4. **Character-specific variants** — `g_SelectedCharactedId` is available
   everywhere, so the Jill/Chris doubling is free.
5. **Timed and restricted runs** — need new bookkeeping (a run timer, a
   "weapon picked up" flag, a "healed" flag, per-room kill counts). Each is
   small on its own but they are the expensive tier.
